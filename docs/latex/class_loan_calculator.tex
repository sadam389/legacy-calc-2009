\doxysubsection{Detailed Description}
A class to handle loan and EMI calculations. 

The \doxylink{class_loan_calculator}{Loan\+Calculator} class provides methods to calculate monthly payments, total interest, and effective interest rates based on loan amount, tenure, and interest rate.
